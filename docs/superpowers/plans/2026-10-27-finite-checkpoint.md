# Finite checkpoint implementation plan

> **For agentic workers:** Use executing-plans for implementation, with independent proof and final branch review.

**Goal:** Prove and implement a rigorously charged finite upper improvement
for the unchanged original seven-budget decision.

**Architecture:** Exact extremal-population arithmetic supports one narrow
callback auditor. A separate canonical checker certifies its uniform cost,
and a complete real-loss proof supplies universal validity and completeness.

**Tech stack:** Python 3.11 standard library, unittest, Markdown.

**Spec:** [Finite checkpoint design](../specs/2026-10-27-finite-checkpoint-design.md).

## Review focus

Strict cutoff at atoms; all head-bin endpoints including the final top;
unsafe or boundary tables outside the margin class; uniform prospective
permutation without conditional-on-survival concentration; shared-label
charging and final full-family consistency; rational-program versus
all-real theorem domains; explicit blind branch and error allocation.

## Decisions and evidence

- This phase follows exploratory schedules and independent exact screens;
  its internal protocol freeze is not external preregistration.
- The program tests only budgets 1,2,4 statistically. Failure of another
  budget's actual head bound sends the table to census. This is sufficient
  for the original margin class and reduces unsupported generality.
- The default disables blind certification. The optional mixed mode makes
  the mathematically admissible empty-query event explicit to a caller.
- Six arithmetic and eight callback tests were observed failing before
  implementation, then passed normally and under optimized standard-library
  Python. The callback exercises each of the three stopping checkpoints and
  fully charged completion on boundary-safe tables.
- Fresh code and theorem reviews found no blocking issue. The proof review
  independently recomputed all 2439 exact bin/checkpoint bounds without
  writing the production artifact. The saved-run obligation remains open.
