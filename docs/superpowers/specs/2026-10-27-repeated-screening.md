# Finite repeated-screening working draft

Prepare a public, explicitly unreviewed finite theoretical separation between
repeated screening with cached exact adjudication and three restricted policy
classes. This is a follow-up to the existing published project, not a claim of
field impact, scientific priority, or empirical LLM usefulness.

The model has a fixed finite score table on the 1/c grid. Independent cheap
ratings have probability 1/4+y/2 and cost 1; exact revelation costs c. The
auditor must have false-certification probability at most delta on every
unsafe table and almost surely certify every safe table, including the
boundary. Compare worst expected payment on the same margin class.

Deliver a self-contained proof, a callable standard-library auditor, an exact
rational numerical certificate for the two already explored examples, and
an independent finite absorbing-chain calculation. Charge every paid walk
step and exact purchase. The runnable auditor uses integer likelihood
comparisons, caches revealed scores, and rejects unsupported callback values.
An optional paid-rating cap returns inconclusive and does not preserve the
uncapped completeness promise. No allocation proportional to population size
is needed before observing items.

No downloads, installations, model calls, or outreach. Added storage must
stay below 2 GB. Publish only an unmerged draft PR; preserve all existing
scientific sources, results, and releases. Disclose substantial Codex
assistance, exploratory parameter selection, lack of independent review,
and the owner's report that he has not yet checked the project.

Independent review agents are currently unavailable due to the account limit.
Self-review and tests are evidence of software conformance, not substitutes
for independent proof review. The overall research/fellowship goal remains
open after this draft.
