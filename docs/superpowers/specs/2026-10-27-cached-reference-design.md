# Computation-bounded cached audit reference implementation

The user authorized continued offline research with no downloads, installations, model calls, or outreach, and less than 2 GB added storage. The v0.13 finite-grid theorem is public, but its cached likelihood construction is not executable. This phase implements that construction with conservative arithmetic and a charged finite-proposal fallback. It is supporting software for the existing theorem, not a new generic testing method or evidence of real-model savings.

Independent exploratory screens found that a head-plus-checkpoint finite-population bound did not improve the original 1934.2 benchmark. A killed-walk occupancy refinement tightens larger-instance bounds but likewise does not improve that original benchmark. Retain those screens locally; do not promote them as a main scientific advance. The release must state this distinction and preserve every older pinned source/artifact.

## Interface and mathematical contract

Add `goodhart_audit/cached_math.py` with `design(prompts, pool_size, budgets, tau, epsilon, delta, eta=Fraction(1)) -> CachedDesign`. Integers are strict integers; probabilities/margins/surcharge are integers or Fractions, never floats or booleans. Accept `0<epsilon<tau<1`, `0<delta<1`, `eta>0`. State the factor-17 corollary only in the v0.13 rare-risk range on factor-two-separated grids.

The immutable design contains original inputs, exact winner weights, per-budget integer cumulative rank masses with denominator `comb(m,n)`, integer log threshold and increments, their dyadic scale, a per-budget proposal cap, the chosen mode (`prefix` or `likelihood`), deterministic prefix cutoff, exact conservative expected-label bound, and the scope of any factor guarantee. A rank proposal chooses a uniform integer ticket in `[0,comb(m,n))`; its containing cumulative interval selects the rank. A separate uniform prompt index gives the exact item law. No item table is expanded at design time.

Add `goodhart_audit/cached.py` with `audit(prompts, pool_size, budgets, tau, epsilon, delta, oracle, eta=Fraction(1), randbelow=None) -> AuditResult`. It builds and validates its own design. The callback `oracle(prompt_index, rank_index)` uses zero-based indices and returns a fixed correct exact loss in `[0,1]`; only first acquisition calls it. Every proposal, including cache hits, uses a fresh Bernoulli coin sampled by exact integer comparison. `randbelow` defaults to `secrets.randbelow`; an injected generator must return a strict integer in range and is intended for reproducibility/tests. Statistical guarantees assume independent uniform draws, not adversarial callback randomness.

Process budgets in increasing order. Pass a budget on conservative likelihood threshold crossing or exact support completion. Issue only the original whole-family certificate. On a proposal cap, acquire the deterministic prefix, check worst-case completion, then census the remaining positive union support if needed. Prefix mode starts with that deterministic procedure. Reuse all cached labels and count every actual acquisition. On an unsafe exact evaluation, return `not_certified`; safe tables must finish. Return immutable acquisition trace, per-budget pass reasons, proposals, distinct count, mode/fallback reason, and design bound. No user-facing production CLI or external annotation service is required in this phase; the callback API is the complete deliverable.

## Conservative arithmetic and cost

Let theta=tau-epsilon, u=log((1-theta)/(1-tau)), v=log(tau/theta), L=log(1/delta). Compute rigorous rational log intervals via range reduction and the positive atanh series. Round u down and -v down to integer increments divided by `S=2^B`, and L up to a threshold ell. Refine until positive lower drift `d_-=(1-theta)*u_- - theta*v_+` is certified. The implemented likelihood is no larger than the true likelihood. Its expected proposals are at most `c_-=(ell+u_-)/d_-`; shared-cache expected acquisitions are bounded by `B_-=sum_r min(P,c_-*sum_n w_n(r))`.

Require log interval width at most `1/S`, giving at most `2/S` downward error per step and `ell<=L+2/S`. A rational upper square-root enclosure gives psi_+ >= sqrt(theta*tau)+sqrt((1-theta)*(1-tau)). Put `phi=psi_+/(1-1/S)` and `A0=sqrt_upper(1/delta)/(1-1/S)`. Refine until phi<1. On a margin table the probability of no statistical crossing by M is at most `A0*phi^M`. Choose M using rigorous log intervals to certify `A*len(K)*A0*phi^M<=eta`, where A=P*k_epsilon. Avoid constructing powers with millions of denominator bits: certify the logarithmic inequality with rational intervals.

Fallback adds at most A labels on every margin table, so the likelihood mode bound is `B_-+eta`. Choose prefix mode if `A<=B_-+eta`. The default guarantee is therefore `min(A,B_-+eta)`. In the v0.13 factor-two rare-risk domain, additionally refine/check `c_- <= (17/8)*tau*L_lower/epsilon^2`; then the implemented auto mode has cost at most `17F+eta`. This is a worst expected distinct-label bound, not a measured cost or an optimal leading constant.

Initial implementation caps: pool size <=1024, total items <=100000, rank-target pairs <=250000, probability/margin/surcharge numerator and denominator <=64 bits, and total permitted virtual proposals <=2000000 in likelihood mode. Reject unsupported designs before invoking the oracle. Prefix mode need not allocate or run virtual streams. Oracle losses must be int/Fraction with denominator <=1000000. This is a bounded rational reference implementation; the ideal mathematical construction covers arbitrary real fixed losses. Cap log refinement and intermediate bit sizes explicitly and fail before allocation if a design exceeds the implementation domain. Proposal-count caps do not claim deterministic bounds on RNG rejection bits or wall time.
