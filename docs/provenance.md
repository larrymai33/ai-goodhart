# Provenance and contribution disclosure

This initial release was commissioned by Larry Mai and developed with substantial Codex multi-agent assistance on 26 October 2026. The repository already existed with an MIT license naming Larry Mai.

The v0.1 fixed-draw release is retained. The v0.2 anytime unique-label extension was implemented with the same substantial Codex assistance. Its verification includes 90 passing tests, scalar/vector conformance checks, source/output integrity checks, and a separate full rerun reproducing both result tables byte for byte. These checks were performed within this assisted development session; they are not independent human replication.

The v0.3 follow-up has the same assistance disclosure. It corrects an incomplete abstract-only prior-art comparison, adds a finite-pool remainder and joint-limit proof, and implements established optimized-proposal objectives as stronger baselines. Its 1,600 new synthetic paths reuse the scenarios and paired seeds behind 4,000 existing paths; no new holdout is claimed. The protocol and release-manifest pin were committed before the new measurements. All 105 tests pass, and a separate rerun reproduces the combined CSVs, optimized designs, and theorem-check JSON byte for byte. Separate agent contexts reviewed proofs, numerical optimization, provenance guards, and report claims.

Codex performed the initial problem selection, literature search, proof drafting, software implementation, synthetic experiment execution, figure generation, and documentation. Separate agent contexts reviewed the mathematics and code. Their feedback led to regression tests and fixes. These are **agent reviews**, not independent human review, institutional endorsement, or conference peer review.

No credential values, account data, or private datasets are present in the project.

The v0.1 protocol was committed before measurement as `2ec734b`. The v0.2 statistical foundation is established work: [Shekhar et al., Risk-limiting Financial Audits via Weighted Sampling without Replacement, UAI 2023](https://proceedings.mlr.press/v216/shekhar23a.html). The implemented weighted-without-replacement betting process specializes that method to several best-of-N risk targets and a shared rank-aware acquisition plan. Generic confidence sequences, fractional bets, and time-uniform validity are not claimed as new. The contribution under assessment is the rank-family specialization, auditable implementation, and measured synthetic tradeoffs.

The v0.1 contribution is a public, testable artifact with a candidate specialized theorem, explicit assumptions, attribution, and negative results. The v0.2 implementation addresses its unique-label stopping limitation without changing the earlier guarantee. Independent human reproduction, external novelty assessment, real-model validation, and demonstrated practical adoption are not claimed for either version. The user's offline constraint continues: no downloads, model inference API calls, or external outreach are part of this extension.
